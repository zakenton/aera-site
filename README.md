# Aera — hosted pages

Static pages for the Aera App Store submission: Privacy Policy + Support.
Published via GitHub Pages from the root of this repo's `main` branch.

## Files

- `index.html` — landing, links to both
- `privacy.html` — Privacy Policy URL
- `support.html` — Support URL
- `.nojekyll` — serve files as-is on GitHub Pages (no Jekyll build)

## URLs

- `https://zakenton.github.io/aera-site/privacy.html`
- `https://zakenton.github.io/aera-site/support.html`

Paste these into App Store Connect: Privacy Policy URL (App Privacy) and
Support URL (App Information). Confirm both open in a private browser window
first — no login, no 404 (Pages can take a minute or two after the first push
to go live).
